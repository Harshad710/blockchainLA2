402

            

              
x402 HTTP Payment Protocol

              

                TablePulse native machine-to-machine micropayments powered by the x402 standard on Base Sepolia.
              

            

          


          

            

              
STEP 01

              
Client Request

              
Client makes standard HTTP POST to /api/v1/profile without payment.

            

            

              
STEP 02

              
402 Challenge

              
Server returns HTTP 402 with price ($0.001), network (Base Sepolia), and payee address.

            

            

              
STEP 03

              
Sign & Settle

              
Client SDK signs EIP-712 payment payload and resubmits. TablePulse profiles and returns report.

            

          


          
Programmatic Integration Snippets


          

            

              TypeScript / Node.js with @x402/fetch
              
            

            
import { x402Client } from '@x402/core/client';
import { registerExactEvmScheme } from '@x402/evm/exact/client';
import { wrapFetchWithPayment } from '@x402/fetch';
import { privateKeyToAccount } from 'viem/accounts';

const account = privateKeyToAccount(process.env.BUYER_PRIVATE_KEY);
const client = new x402Client();
registerExactEvmScheme(client, { signer: account });

const paidFetch = wrapFetchWithPayment(globalThis.fetch, client);

const res = await paidFetch('http://localhost:3000/api/v1/profile', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    datasetName: 'orders.csv',
    content: 'order_id,amount\n101,45.50\n102,12.00',
  }),
});

const report = await res.json();
console.log('Quality Grade:', report.summary.qualityGrade, 'Score:', report.summary.qualityScore);
